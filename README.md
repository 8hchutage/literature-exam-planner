# 文学考研备考规划

一个以任务树、截止日期和项目进度为核心的备考工具。先从政治、英语和汉语言文学基础开始，确定院校后再配置专业课一、专业课二。

[直接打开网页版](https://8hchutage.github.io/literature-exam-planner/)

## 开始使用

打开网页即可使用。在「备考设置」填写目标院校、考试年份和总截止日期，随后在任务树中建立学科、小板块和任务。所有设置都可以随备考进展调整。

首次打开时会创建通用的空白计划，包含政治、英语、古代汉语、现代汉语、中国现当代文学、中国古代文学、语言学纲要、外国文学等默认学科。可自行增删专业基础学科、拆分任务和整理资料。

## 主要功能

- **总览**显示完成度、倒计时、预计时长、已投入时长，以及从昨天起向后五个自然日的计划。
- **任务树**支持多层子任务，通过左侧手柄排序。任务可拖到大板块根目录或另一个小板块下，原有子任务层级、任务状态和关联记录会一起保留。拖拽始终保留任务性质。
- **板块备注**通过名称旁的 💬 独立展开和收起。板块设置内支持删除板块，可选择先转移内容，或确认一并删除任务及学习时间记录。
- **任务池**显示末级任务，提供状态、学科、优先级和截止日期筛选，并展示父级路径。
- **学习记录**支持关联任务的学习时间和直接记到学科的碎片化练习，提供月历、周历与可编辑的当天计划。
- **备考时间轴**支持具体日期、多日范围和按月上中下旬估计的日期。可设置重要程度、颜色、备注和相关网址，支持颜色筛选及整体折叠。节点同步显示在月历与周历。
- **资源库**支持自由建立文件夹、拖拽整理层级、搜索和任务引用。资源及整个文件夹均可拖进归档桶，归档与恢复保留文件分级。
- **备份迁移**可在备考设置导出和导入 JSON。导入采用合并方式，已存在的记录 ID 和同日计划以当前记录为准，其余记录按关联关系新增。
- **专业课配置**可将已有学科或任务关联到专业课一、专业课二，复用同一份任务进度。

## 数据保存与备份

GitHub Pages 版免登录使用，学习数据保存在当前浏览器的 IndexedDB 中。仓库提供功能代码和通用初始模板，个人任务、学习记录、资源、错题和计划由使用者在自己的浏览器中创建。

同一网址、同一浏览器环境下再次打开会读取原来的记录。手机和电脑、不同浏览器各自保存数据，需要通过导出与导入 JSON 迁移。网页更新会继续读取原来的浏览器数据库。

建议定期在「备考设置」点击「导出备份」，把 JSON 保存在自己的文件夹。清理浏览器站点数据、使用无痕模式或更换设备时，请先做好备份。备份中包含个人填写的内容，应保存在自己的设备或私人存储空间。

## 在自己的电脑运行

下载仓库 ZIP 并解压，或使用 Git 克隆本仓库。进入包含 `index.html` 的文件夹，通过本地 HTTP 服务打开网页。

Windows 已安装 Python 3 时，可以在该文件夹的终端运行以下命令。

```powershell
py -m http.server 8080
```

随后打开浏览器访问 `http://localhost:8080/`。使用固定的地址和端口，可以继续读取该地址下保存的学习数据。

## 部署到自己的 GitHub Pages

将本仓库 Fork 到自己的账号，进入仓库的 Settings → Pages，将发布来源设为 Deploy from a branch，选择 `main` 分支和根目录 `/ (root)`，保存后等待 GitHub 完成发布。

仓库使用相对路径加载文件，适合 GitHub Pages 的项目子路径。浏览器侧使用现代 JavaScript 模块，页面通过 HTTPS 或本地 HTTP 服务访问。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面入口与导航 |
| `app.js` | 总览、任务树、任务池、日历、资源库和编辑交互 |
| `style.css` | 页面样式与手机布局 |
| `model.js` | 通用初始模板、任务层级、进度计算、移动删除及备份合并规则 |
| `pages-storage.js` | 浏览器 IndexedDB 存储与记录版本检查 |
| `.nojekyll` | GitHub Pages 静态发布标记 |
| `.gitignore` | 排除本地数据库、备份和环境配置 |

## 开发说明

本仓库交付可直接发布的静态版本，修改 HTML、CSS 或 JavaScript 后提交即可更新 GitHub Pages。界面功能通过 `pages-storage.js` 读写浏览器数据，业务规则集中在 `model.js`，方便进一步扩展。

完成率按末级可执行任务的预计时长加权计算。独立学科记录与关联任务的学习记录共同计入实际投入时长。
